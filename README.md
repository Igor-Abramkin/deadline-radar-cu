# hx-deadline-radar

Telegram-бот, который следит за дедлайнами в LMS Центрального университета
(my.centraluniversity.ru) и пишет в группу.

- 🆕 новое задание появилось в LMS
- 📅 / ⚠️ / 🔥 за 3 дня, за сутки и за 3 часа до дедлайна
- 🔁 дедлайн перенесли
- `/deadlines` — список на две недели вперёд

В группе с темами бот пишет только в тему `THREAD_ID`. Команды из других тем он
удаляет, а ответ присылает в тему дедлайнов. Каждая команда в группе
срабатывает не чаще раза в 5 минут (`GROUP_COOLDOWN_SEC`), повторы бот молча
удаляет. В личке лимит 30 секунд на человека (`PRIVATE_COOLDOWN_SEC`).

## Как это работает

LMS — Angular SPA поверх JSON API (`/api/micro-lms/*`). Бот читает
`/tasks/student`, а не `/deadlines`: второй скрывает задания, которые владелец
аккаунта уже сдал, а группе напоминание нужно всё равно.

Вход в `id.centraluniversity.ru` закрыт Yandex SmartCaptcha и SMS-кодом, поэтому
логин один раз делается руками в браузере (`bun run login`). Дальше бот ходит в API
с кукой `bff.cookie`. Сервер продлевает её на 14 дней при каждом запросе, бот
сохраняет новую в `data/cookie.txt`, так что при опросе раз в 30 минут сессия
не истекает. Если всё-таки истечёт, бот напишет `OWNER_ID` в личку: нужно
запустить `bun run login` на ноутбуке и отправить боту в личку команду
`/session …`, которую выведет скрипт.

## Локально

```sh
bun install
bunx playwright install chromium
cp .env.example .env          # заполнить
bun run login                 # откроется браузер: капча, SMS
bun start
```

## Сервер (Coolify)

Build pack Dockerfile, постоянный том на `/app/data`, порт не публикуется.
Env: `BOT_TOKEN`, `CHAT_ID`, `OWNER_ID`, `EXCLUDE_COURSES`, `CU_COOKIE`
(значение из `data/cookie.txt` после логина; нужно только для первого старта,
дальше бот обновляет куку в томе сам). Сервер в Москве: Telegram туда ходит
через туннель хоста, LMS напрямую.

1. Создать бота у @BotFather, токен в `BOT_TOKEN`.
2. Добавить бота в группу, отправить `/chatid`, id в `CHAT_ID`.
3. Свой Telegram id в `OWNER_ID` (например, через @userinfobot).
4. Перезапустить бота.

При первом запуске бот ничего не постит: он запоминает текущие задания и
дальше сообщает только об изменениях.

Бот видит LMS глазами одного аккаунта: задания чужих треков и уровней, на
которые этот аккаунт не записан, в ленту не попадут. `EXCLUDE_COURSES` —
регулярка по названию курса, чтобы выкинуть лишнее (по умолчанию ознакомление
с приказами).
